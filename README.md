# SunDocument

仿 MT 管理器的 Android **双栏**文件管理器，Kotlin + Jetpack Compose 编写。
打开方式、过滤、批量重命名、压缩包内编辑、文件对比、十六进制编辑与 APK 逆向面板按 [MT 用户手册](https://mt.cc/guide/) 的功能与手势逐项对齐。
由 **GitHub Actions 自动编译并使用固定密钥签名**，内置基于 **GitHub Release** 的应用内更新：
多线路加速、进度条、更新弹窗、下载完成自动调起系统安装程序。

## 界面结构

```
┌────────────────────────────────────────────────────────────┐
│ ☰  /storage/emulated/0/Download                        ⋮  │  顶栏：聚焦栏的真实路径
│    ▸ 12   ▤ 34   36.24 GB / 128.00 GB                     │  图标 + 数量 + 精确容量
├───────────────────────────┬────────────────────────────────┤
│ ████████████████████████ │   ░░░░░░░░░░░░░░░░░░░░░░░░░  │  聚焦栏整片底色加深
│ 📁 ..                     │ 📁 ..                          │  固定的三点「..」上级行
│ 📁 DCIM                   │ 📄 report.pdf      12.40 MB    │  线性图标，无底框
│ 📄 notes.md        1.24 KB│ 📁 backup                      │
├───────────────────────────┴────────────────────────────────┤
│           ←        →        ＋        ⇄        ↑           │  底栏 5 个纯图标
└────────────────────────────────────────────────────────────┘
```

- **顶栏**：`☰` 侧边栏；中间是**当前聚焦栏**的绝对路径与「目录数 / 文件数 / 已用·总容量」（两位小数），数字用图标区分而不写"文件夹""文件"；右侧 `⋮` 展开工具栏。
- **双栏**：各自维护路径、历史栈、选中项与**滚动位置**。手指按下或移到哪一栏，哪一栏就获得焦点；聚焦栏用整片底色差 + 内容不透明度（1.0 / 0.86）区分，没有栏头路径、没有 A/B 标签、也没有高亮线。
- **`..` 行**：每栏顶部固定一行三点文件夹，点击回上一级。
- **返回键**：在聚焦栏内按返回 → 回到上一级；只有已在根目录时才提示退出。
- **底栏**：← 后退、→ 前进、＋ 新建、⇄ **同步窗口（长按过滤）**、↑ 上一级（**长按跳转路径**）；**从底栏上滑打开书签**；多选后切换为 复制 / 剪切 / 重命名 / 删除 / ⋯ 更多。
- **多选**：在任意一栏**左右滑动**即可进入多选并连续选中划过的行；选中条右侧提供 全选 / 反选 / 类选，⋯ 里还有 压缩 / 批量重命名 / 分享 / 对比 / 属性。

## 目录访问

| 场景 | 行为 |
| --- | --- |
| 内部存储、SD 卡 | 授予「所有文件访问权限」后全量读写，无虚拟条目 |
| `/`、`/system`、`/data`、`/vendor`、`Android/data` | 普通应用被 SELinux / scoped storage 拦住，**在设置里获取 Root 后直接读真实内容**（`ls` / `cat` / `cp` / `chmod`） |
| 未 Root 且不可读 | 显示一行原因 + 「获取 Root」「返回上级」，不崩溃、不再伪造挂载点 |

Root 是**手动开启**（设置 → 系统访问 → Root 权限），避免未 Root 设备每次进入受限目录都弹授权框。

## 文件与打开方式

| 类型 | 默认行为 |
| --- | --- |
| 文件夹 | 进入 |
| 文本 / 代码 | 内置编辑器（高亮、补全、行号、撤销重做、查找替换） |
| 图片 | 内置全屏查看器：双指缩放、双击放大、拖动平移，**左右滑动切换同目录上一张/下一张**，GIF / 动态 WebP 直接播放 |
| 视频 | 内置全屏播放器：点按显隐控制条、拖动进度、**左右滑动切换上下一个视频** |
| 音频 | **底部弹窗式播放器**（不占满屏）：封面、进度、上一首 / 下一首、暂停续播；点遮罩不关闭，只能点关闭或按返回 |
| Word / Excel / PPT | **内置文档查看器**：docx / xlsx / pptx / odt / ods / odp / csv / tsv 直接读文字与表格，可切工作表；旧版 doc/xls 走系统应用 |
| zip / jar / apk / aar / epub / tar / tar.gz / gz | 内置压缩包浏览器，逐层进入；**点文件直接解压到缓存并进入编辑器 / 打开方式**，不再弹只读预览；支持解压全部、解压到当前目录 |
| apk | 打开方式面板另含 **安装包信息**（包名 / 版本 / 签名证书 / 权限 / 组件 / ABI / dex 列表）、**AXML 反编译**（AndroidManifest 还原为文本）、**Dex 结构浏览**（类 → 方法 / 字段 / 字符串） |
| pdf | 调系统应用；没有可用应用时弹「打开方式」 |
| 未知类型 / 二进制 | 仿 MT 的**打开方式面板**：文本 / 十六进制 / 图片 / 压缩包 / 其他应用，可勾选「总是用此方式打开 .xxx」 |

**大文本策略**

- 打开只取前 200 KB（大多数文件一次读完，与普通编辑器完全一致，行号从第 1 行开始连续）；
- 继续向下滑动时自动追加下一段，追加到 1.2 MB 后改为底部「载入下一段」按钮，不再有分页和大段空白；
- 段边界对齐到行尾与字符首字节，逐段拼接与原文完全一致（有单测覆盖）；
- 保存时写入改过的前段，再把磁盘上尚未载入的尾部原样接回去，几百 MB 的日志也不整篇重写；
- 任意大小的二进制可用**十六进制查看器**分页浏览；大图按屏幕采样解码。

## 文件管理

| 操作 | 说明 |
| --- | --- |
| 长按菜单 | 仿 MT：打开 / 打开方式 / **复制到另一栏** / **移动到另一栏** / 复制 / 剪切 / 重命名 / 压缩 / 解压到当前目录 / 安装 / 用文本打开 / 分享 / 属性 / 多选 / 复制路径 / 收藏 / 删除 |
| 复制 / 剪切 / 粘贴 | 多选 + 递归目录，跨栏操作，同名自动 `名称 (1)` |
| 删除 / 重命名 / 新建 | 递归删除、二次确认、名称校验；不可写时落到 Root |
| 批量重命名 | **MT 表达式**：`{P}` 原名、`{S}` 后缀、`{1}` 递增、`{z1}` 补零、`{T:yyyyMMdd}` 时间、`{AN}/{AP}/{AV}/{AC}` APK 名称/包名/版本，实时预览，同名自动避让 |
| 压缩 | 可选 **ZIP / TAR / TAR.GZ**，多选打包，自动补扩展名 |
| 解压 | 解压全部或解压到当前目录，带路径穿越防护 |
| 压缩包内编辑 | 长按条目可 **重命名（改完整路径即移动）/ 删除**；顶栏「＋」把当前栏选中的文件加入包内；点开文件编辑并保存后**自动写回 zip** |
| 对比 | 选中两个文件后 ⋯ → 对比：文本逐行着色 diff，文件夹 / 压缩包输出清单报告（仅一侧、大小不同、类型不同） |
| 终端 | 侧边栏「终端」：内置 `/system/bin/sh`，`cd` 维护工作目录，`clear` / `help` 可用 |
| 校验和 | SHA-256 + MD5，一键复制 |
| 属性 | 路径、类型、递归大小（0.01 精度）、子项数、修改时间、权限、zip 条目数 |
| 权限 | 选中单项可 `chmod`（000–7777），系统目录配合 Root |
| 收藏夹 / 最近访问 | 侧边栏与 ⋮ 菜单快速跳转 |
| 搜索 | **按名称**或**按内容**两种模式：内容模式给出「文件 + 行号 + 该行片段」，点击直接打开并定位到该行 |
| 分享 / 复制路径 | FileProvider 分享，避免暴露 `file://` |

## 内置编辑器

- **语法高亮**：Kotlin / Java / JavaScript / TypeScript / Python / Shell / C / C++ / C# / Go / Rust / PHP / Ruby / Swift / JSON / XML / HTML / CSS / SQL / YAML / Properties / Markdown / Smali / Gradle / Lua / Dart / Dockerfile，配色随主题切换。
- **代码补全（对齐 VS Code）**：
  - 三级模糊匹配 —— 前缀 > 驼峰缩写（`NPE` → `NullPointerException`）> 子序列，逐字符记录命中位置并高亮；
  - 排序综合匹配质量、文档内词频、同文件符号定义、上下文权重；
  - 上下文感知：`obj.` 出成员、`import ` 出**真实类名**、`@` 出注解、普通位置出关键字 / 片段 / 符号 / 变量；
  - **每一项都有说明**：浮层底部固定展示「这个关键字 / 类 / 函数是干什么用的」，例如 `android.content.Context` → 「访问资源、启动组件、取系统服务的入口」；
  - 文档索引带缓存（长度 + 首尾片段做键 + 400 ms 降频），连续输入不重复全量扫描；
  - ↑↓ 选择、Tab/Enter 接受、Esc 关闭。
- **编辑能力**：行号与当前行高亮、自动缩进、括号自动闭合、撤销 / 重做、查找、查找替换、跳转行、自动换行、**双指捏合缩放（6–30sp）**、另存为。
- **MT 式细节**：**长按行号选中整行，再长按另一行选中区间**；菜单里可一键 **切换注释**（`//`、`#`、`--` 按语言自动选择）、**切换换行符 LF / CRLF**（写出时生效，编辑区始终是 `\n`）、**选中当前行**。
- **编码**：点状态栏的编码名即可在 UTF-8 / GB18030 / GBK / Big5 / Shift_JIS / EUC-KR / UTF-16LE / UTF-16BE / ISO-8859-1 / windows-1252 之间切换并重新读取。
- **HTML / Markdown 预览**：打开这两类文件时，顶栏出现预览按钮，直接在应用内渲染（Markdown 支持标题、列表、表格、代码块、链接与图片；相对路径资源按文件目录解析）。
- **输入不卡顿**：文本由界面持有，打字不触发整页重组；行号只绘制可见的几十行；行数、行列号在停手后后台计算；缩放先按图层预览、松手才提交字号，捏合过程不重排文本。
- **代码高亮**：Markdown 单独按行着色（标题、引用、列表、行内代码、链接），代码注释 / 字符串 / 数字 / 注解随主题取色。
- **历史版本**：每次保存前留档（单文件 30 版），可预览、恢复、清空。

## 主题

设置 → 外观：**跟随系统 / 白天 / 黑夜**，即时生效并持久化。

1. 启动 1.6 秒后静默检查（可关），或在 ⋮ / 设置 / 侧边栏手动检查；
2. 读取 `suibian-sun/SunDocument` 的 latest Release，按语义版本比较（忽略 `+ci.x`）；

4. 下载优先走 `ghfast.top` → `gh-proxy.com` → `ghproxy.net` → `gh.llkk.cc`，失败自动切换，最后回退直连；

## 设计规范

- **层级**：只用 1%–3% 的背景明度差分，不用描边黑框；层次靠光，不靠框。
- **少即是多**：不在界面上写解释性副标题，用图标、位置与留白表达含义。
- **字重**：暗色下整体降一档，抵消亮字光渗。
- **数字**：全部等宽字体，容量与文件大小保留两位小数。
- **动效**：统一 180 / 300 / 380 / 460 / 600 ms 与 ease-in / ease-out / ease-in-out 令牌，整体放慢一档再看得到「从哪来、到哪去」。层级切换左右推开、路径变化淡入上移、补全浮层弹性出现、底栏多选变形、栏聚焦底色过渡、按压回弹、数字滚动、骨架屏、汉堡变叉、圆形扩散、对勾粒子。
- **图标**：文件夹为实心双层造型；文件为统一「纸张 + 折角」轮廓，颜色与标签随扩展名；图片与视频直接显示首帧缩略图。
- **聚焦**：两栏之间只有一条内容色细线；当前栏靠底色与内容亮度区分，不再出现蓝色高亮线。

## 构建与签名

```bash
export ANDROID_HOME=/path/to/android-sdk
./gradlew assembleRelease -PappVersionName=1.0.7 -PappVersionCode=15
```

正式签名通过环境变量注入（缺省回退 debug 签名）：`SIGNING_KEYSTORE`、`SIGNING_STORE_PASSWORD`、`SIGNING_KEY_ALIAS`、`SIGNING_KEY_PASSWORD`。

仓库 Actions Secrets：`KEYSTORE_BASE64` / `KEYSTORE_PASSWORD` / `KEY_ALIAS` / `KEY_PASSWORD`。
**所有版本必须使用同一份 keystore**，否则无法覆盖安装，请务必备份 `sunfile-release.jks`。

## 发布流程

1. 推送到 `main`：CI 运行单元测试、编译、验签，产物作为 artifact 上传；
2. `git tag v1.0.7 && git push origin v1.0.7`：CI 创建 GitHub Release 并附 APK + SHA256SUMS；
3. 已安装旧版本的用户打开应用即收到更新提示。

`versionName` 取自 tag，`versionCode` 取自 `github.run_number`，保证单调递增。

## 权限

- `MANAGE_EXTERNAL_STORAGE`：Android 11+ 全盘读写（需在系统设置中授予）
- `READ / WRITE_EXTERNAL_STORAGE`：Android 6–10 运行时权限
- `REQUEST_INSTALL_PACKAGES`：应用内更新安装
- `INTERNET` / `ACCESS_NETWORK_STATE`：检查更新与下载

## 已知限制

- `/data`、`/system`、`Android/data` 等目录受 SELinux 与 scoped storage 限制，**未 Root 时任何第三方应用都读不到**（MT 管理器同样依赖 Root）。本应用提供一键 Root，获取后即为真实数据。
- zip / tar / tar.gz / gz 可内置浏览与创建；**7z / rar / bz2 / xz 仍需第三方应用**（读写库体积与授权成本都不适合内置）。
- 旧版二进制 doc / xls / ppt 无法在应用内解析，会提示用其他应用打开（docx / xlsx / pptx 不受影响）。
- 超过 120 KB 的文本不再着色（整段重排已经很重，优先保证输入流畅）。
- 分段载入的超长文件暂不支持撤销 / 重做，避免与未载入的尾部错位。
- 十六进制编辑器单次最多载入 6 MB；更大的文件只读浏览，保存按钮会隐藏，避免只写回前半段。
- **逆向部分只做到「看」**：AndroidManifest 反编译、dex 类 / 方法 / 字段 / 字符串浏览、APK 签名与组件信息；Smali 编辑、`resources.arsc` 编辑、AXML 回编译、APK 重签名需要完整的反编译与签名工具链，不在本应用范围内。
- 编辑器暂不支持多文件标签页（MT 的「保留文件」），关闭时会提示保存；终端直接调用系统 `sh`，没有内置 bash / coreutils 扩展包，`ls -l` 等行为以系统自带实现为准。
