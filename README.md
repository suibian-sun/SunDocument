# SunDocument

仿 MT 管理器的 Android **双栏**文件管理器，Kotlin + Jetpack Compose 编写。
打开方式、过滤、批量重命名、压缩包内编辑、文件对比、十六进制编辑与 APK 逆向面板按 [MT 用户手册](https://mt.cc/guide/) 的功能与手势逐项对齐。
由 **GitHub Actions 自动编译并使用固定密钥签名**，内置基于 **GitHub Release** 的应用内更新：
多线路加速、进度条、更新弹窗、下载完成自动调起系统安装程序。

## 界面结构

```
┌────────────────────────────────────────────────────────────┐
│ ☰  /storage/emulated/0/Download                        ⋮  │  顶栏：聚焦栏的完整路径
│    12 文件夹 · 34 文件 · 36.24G/128G                        │  一行纯文字，不挂图标
├───────────────────────────┬────────────────────────────────┤
│ ████████████████████████ │   ░░░░░░░░░░░░░░░░░░░░░░░░░  │  聚焦栏整片底色加深
│ 📁 ..                     │ 📁 ..                          │  与普通行同构的上级行
│ 📁 DCIM                   │ 📄 report.pdf                  │  彩色方块图标 + 白纸
│   22-08-01 15:02          │   22-08-01 15:02 12.40M        │  时间在前、大小在后
├───────────────────────────┴────────────────────────────────┤
│           ←        →        ＋        ⇄        ↑           │  底栏 5 个纯图标
└────────────────────────────────────────────────────────────┘
```

- **侧边栏**：顶部固定导航（Logo、名称、明暗切换、竖向三点），三点菜单含 主题跟随系统 / 添加网络存储 / 添加本地存储 / 添加网络分组 / 管理工具分组 / 设置；下方依次为 **本地存储**（根目录、内部存储与自建路径，各带容量进度条与已用/剩余）、**网络存储**（内置六协议客户端，点开直接浏览，可按组折叠）、**工具**（插件管理、远程管理、已安装应用、文本编辑器、终端模拟器、Mcp 服务、更多工具）。
- **顶栏**：`☰` 侧边栏；中间是**当前聚焦栏**的绝对路径（17sp 中等字重，路径变长自动降到 15/13sp）与「文件夹数 · 文件数 · 已用/总容量」，副标题是一行纯文字，不挂图标；右侧 `⋮` 展开工具栏。
- **双栏**：各自维护路径、历史栈、选中项与**滚动位置**。手指按下或移到哪一栏，哪一栏就获得焦点；聚焦栏用整片底色差 + 内容不透明度（1.0 / 0.86）区分，没有栏头路径、没有 A/B 标签、也没有高亮线。
- **`..` 行**：每栏顶部固定一行，用与普通文件夹相同的实心图标，点击回上一级。
- **返回键**：在聚焦栏内按返回 → 回到上一级；只有已在根目录时才提示退出。
- **底栏**：← 后退、→ 前进、＋ 新建、⇄ **同步窗口（长按过滤）**、↑ 上一级（**长按跳转路径**）；**从底栏上滑打开书签**；多选后切换为 复制 / 剪切 / 重命名 / 删除 / ⋯ 更多。
- **多选**：在任意一栏**左右滑动**即可进入多选并连续选中划过的行；选中条右侧提供 全选 / 反选 / 类选，⋯ 里还有 压缩 / 批量重命名 / 分享 / 对比 / 属性。

## 目录访问

| 场景 | 行为 |
| --- | --- |
| 内部存储、SD 卡 | 授予「所有文件访问权限」后全量读写，无虚拟条目 |
| `Android/data`、`Android/obb` | **免 Root**：侧边栏点进去按提示授权一次（SAF），之后可浏览、导出、改名、删除；授权随时可撤销 |
| `/`、`/system`、`/data`、`/vendor` | 普通应用被 SELinux 与内核沙箱拦住，**在设置里获取 Root 后直接读真实内容**（`ls` / `cat` / `cp` / `chmod`）；未 Root 时「系统信息」页会列出哪些目录还能读 |
| 未 Root 且不可读 | 显示一行原因 + 「获取 Root」「返回上级」，不崩溃、不再伪造挂载点 |

Root 是**手动开启**（设置 → 系统访问 → Root 权限），避免未 Root 设备每次进入受限目录都弹授权框。

## 文件与打开方式

| 类型 | 默认行为 |
| --- | --- |
| 文件夹 | 进入 |
| 文本 / 代码 | 内置编辑器（高亮、补全、行号、撤销重做、查找替换） |
| 图片 | 内置全屏查看器：双指缩放、双击放大、拖动平移，**左右滑动切换同目录上一张/下一张**，GIF / 动态 WebP 直接播放；SVG 用 WebView 渲染 |
| 视频 | 内置全屏播放器：点按显隐控制条、拖动进度、**左右滑动切换上下一个视频** |
| 音频 | **屏幕居中的播放器卡片**：封面、进度、上一首 / 下一首、暂停续播；点遮罩不关闭，只能点关闭或按返回 |
| Word / Excel / PPT | **内置文档查看器**：docx / xlsx / pptx / odt / ods / odp / csv / tsv 直接读文字与表格，可切工作表；旧版 doc/xls 走系统应用 |
| zip / 7z / rar / tar / tar.gz / tar.bz2 / tar.xz / gz / bz2 / xz | 内置压缩包浏览器，逐层进入；**点文件直接解压到缓存并进入编辑器 / 打开方式**；加密包就地输入密码；**从包内打开文件后返回仍在原来的目录层级** |
| apk | 打开方式面板另含 **安装包信息**（包名 / 版本 / 签名证书 / 权限 / 组件 / ABI / dex 列表）、**AXML 反编译**（AndroidManifest 还原为文本）、**Dex 结构浏览**（类 → 方法 / 字段 / 字符串）、**资源表编辑** |
| .9.png | **点九图编辑器**：四边补丁线放大成格子，点一下切换拉伸区 / 内容留白 |
| .arsc | **资源表编辑器**：按类型列出条目，可改字符串与整数 |
| pdf | 调系统应用；没有可用应用时弹「打开方式」 |
| 未知类型 / 二进制 | 仿 MT 的**打开方式网格**：三列彩色方块（文本 / 十六进制 / 图片 / 压缩包 / 其他应用），长按任一项直接设为该扩展名的默认；底部左「类型」管理已记住的映射，右「关闭」退出 |

**大文本策略**

- 打开只取前 64 KB（大多数文件一次读完，行号从第 1 行开始连续）；
- 继续向下滑动时自动追加下一段，追加到 256 KB 后改为底部「载入下一段」按钮；
- 超过 12 万字自动关闭整篇语法高亮与补全，超过 32 MB 直接提示改用十六进制编辑器，避免整页卡死；
- 段边界对齐到行尾与字符首字节，逐段拼接与原文完全一致（有单测覆盖）；
- 保存时写入改过的前段，再把磁盘上尚未载入的尾部原样接回去，几百 MB 的日志也不整篇重写；
- 任意大小的二进制可用**十六进制查看器**分页浏览；大图按屏幕采样解码。

### 网络存储

侧边栏「网络存储」点开即进入内置浏览页，六种协议都有真实客户端，不依赖系统里装没装对应 App：

| 协议 | 链接示例 | 说明 |
| --- | --- | --- |
| FTP / FTPS | `ftp://user:pass@host:21/path`、`ftps://…:990` | 被动模式；FTPS 支持显式（21）与隐式（990） |
| SFTP | `sftp://user:pass@host:22/home` | SSH 密码认证，跳过首次 host key 确认 |
| SMB | `smb://user:pass@host/share/sub` | SMB2/3；不写共享名时按常见共享名探测 |
| WebDAV | `webdav://user:pass@host:5005/dav` | PROPFIND 列目录，PUT 上传，MKCOL 建目录，MOVE 改名 |
| 对象存储 | `s3://AK:SK@minio.local:9000/bucket?region=us-east-1` | S3 兼容（AWS / MinIO / OSS 的 S3 模式），AWS SigV4 签名；明文 HTTP 的 MinIO 加 `&http=1` |

浏览页支持：列目录、进入子目录、上传（可多选）、下载到 `Download/SunDocument/<名称>/`、点击文件下载到缓存后交给对应应用打开、新建文件夹、重命名、删除、断线重连。缩略图受设置里「网络缩略图 / 仅 Wi-Fi / 单图上限 / 超时」四项共同控制。

## 内置编辑器

- **语法高亮**：Kotlin / Java / JavaScript / TypeScript / Python / Shell / C / C++ / C# / Go / Rust / PHP / Ruby / Swift / JSON / XML / HTML / CSS / SQL / YAML / Properties / Markdown / Smali / Gradle / Lua / Dart / Dockerfile，配色随主题切换。
- **代码补全（对齐 VS Code）**：
  - 三级模糊匹配 —— 前缀 > 驼峰缩写（`NPE` → `NullPointerException`）> 子序列，逐字符记录命中位置并高亮；
  - 排序综合匹配质量、文档内词频、同文件符号定义、上下文权重；
  - 上下文感知：`obj.` 出成员、`import ` 出**真实类名**、`@` 出注解、普通位置出关键字 / 片段 / 符号 / 变量；
  - **每一项都有说明**：浮层底部固定展示「这个关键字 / 类 / 函数是干什么用的」，例如 `android.content.Context` → 「访问资源、启动组件、取系统服务的入口」；
  - 文档索引带缓存（长度 + 首尾片段做键 + 400 ms 降频），连续输入不重复全量扫描；
  - ↑↓ 选择、Tab/Enter 接受、Esc 关闭。
- **编辑能力**：行号与当前行高亮、自动缩进、括号自动闭合、撤销 / 重做、查找、查找替换、跳转行、自动换行、**双指捏合缩放（6–30sp）**、另存为。
- **MT 式细节**：**长按行号选中整行，再长按另一行选中区间**；菜单里可一键 **切换注释**（`//`、`#`、`--` 按语言自动选择）、**切换换行符 LF / CRLF**（写出时生效，编辑区始终是 `\n`）、**选中当前行**。
- **编码**：点状态栏的编码名即可在 UTF-8 / GB18030 / GBK / Big5 / Shift_JIS / EUC-KR / UTF-16LE / UTF-16BE / ISO-8859-1 / windows-1252 之间切换并重新读取。
- **HTML / Markdown 预览**：打开这两类文件时，顶栏出现预览按钮，直接在应用内渲染（Markdown 支持标题、列表、表格、代码块、链接与图片；相对路径资源按文件目录解析）。
- **输入不卡顿**：文本由界面持有，打字不触发整页重组；行号只绘制可见的几十行；行数、行列号在停手后后台计算；缩放先按图层预览、松手才提交字号，捏合过程不重排文本。
- **代码高亮**：Markdown 单独按行着色（标题、引用、列表、行内代码、链接），代码注释 / 字符串 / 数字 / 注解随主题取色。
- **历史版本**：每次保存前留档（单文件 30 版），可预览、恢复、清空。

## 语法插件

高亮规则可以自己加：把 JSON 放进外部目录的 `plugins/syntax/`，重开编辑器即生效。
首次运行会写好一份 `toml.json` 当样例。

```json
{
  "id": "toml",
  "name": "TOML",
  "extensions": ["toml", "lock"],
  "keywords": ["true", "false", "table"],
  "lineComment": "#",
  "caseInsensitive": false
}
```

可选字段：`blockStart` / `blockEnd` 定义块注释。命中扩展名后，编辑器的高亮与补全关键字都走这份规则。

## MT 插件

MT 的插件包（`.mtp`）里放的是 **Java 源码**，MT 自己编译执行。这里没有编译器，
所以换了一条路：把源码解析成语法树，用内置的解释器跑，同时把 `bin.mt.plugin.api`
用宿主实现顶上。**MT 插件不用改一行代码，装上就能用。**

```
manifest.json      必填，pluginSdkVersion / pluginID / versionCode / name / interfaces / mainPreference
src/*.java         插件源码，可以带 package 与多级目录
assets/*.mtl       语言包，String.mtl / String-zh-CN.mtl
assets/            其它资源，context.getAssetsAsStream("d/a.txt") 读
icon.png           可选，图标
libs/*.jar         第三方库：解成 class 直接进解释器（见下）
```

已实现的 API：

| 范围 | 内容 |
| --- | --- |
| `MTPluginContext` | 插件 id / 版本、`getPreferences()`、语言环境、`getFilesDir()`、`getLocalString()`、`getAssetLocalString()`、`getLanguageNameLocalString()`、`getAssetsAsStream()`、`log()`、`showToast()` |
| `LocalString` | `.mtl` 语言包解析、`get(key)`、`get(key, lang)`、`getOrDefault`、`keySet`、清单里的 `{key}` 本地化 |
| `PluginPreference` | Builder 的 Header / Text / Input / Switch / List，按声明渲染成真正的设置界面，值读写 SharedPreferences |
| `TranslationEngine` / `BaseTranslationEngine` | 名称、源/目标语言、`translate()`，以及 `Configuration` / `ConfigurationBuilder` |
| 语言 | Java 类、继承、字段、构造器、if/for/foreach/while/do/switch/try、字符串与正则、List/Map/File/JSON、`String.format`、`Math`、`Arrays` 等 JDK 调用 |

安装：设置 → MT 插件 → 右上角加号选 `.mtp`；空列表里还能一键装一个示例插件。
装上后详情页能看设置界面、跑一次翻译、看插件日志。

### 依赖 jar 的插件

有些插件把算法放进 `libs/*.jar`。Android 上没有 `d8`，`DexClassLoader` 也加载不了 JVM 字节码，
所以这里写了一个**字节码解释器**：解析 `.class` 的常量池、方法与 `Code` 属性，按指令直接执行，
和源码类共用一套对象模型（实例是同一个 `JObj`，静态字段挂在同一个 `JClass`）。

覆盖常规 javac 会生成的指令：常量、局部变量、栈操作、算术与类型转换、比较与跳转、
`tableswitch` / `lookupswitch`、字段读写、四种方法调用、`new` / 数组 / `athrow` / `checkcast`、
异常表（try/catch）。宿主类（String、StringBuilder、List、Map、File、Android API）走反射桥。

`jsr` / `ret` / `invokedynamic` 会明确报错（lambda 会编译成 `invokedynamic`，改用匿名类即可）。
单个方法执行超过 2000 万条指令会判定为死循环并中断，不会卡住界面。

原来的「脚本动作」插件（`manifest.json` 里写 `actions`，用 shell 或 dex 类实现）
仍然支持，入口在设置 → 插件。

**resources.arsc**：按 AOSP 的二进制布局解析表头、全局字符串池、包、类型与条目，
把 `@0x7f…` 还原成 `类型/名称`，限定符写成 `zh-rCN-hdpi-v26` 这种可读形式。
条目详情里可以改字符串（重建字符串池，保持下标不变）、整数、十六进制、布尔、颜色与引用；
改的是 APK 里的条目时，保存会把整个 zip 重写一遍——**签名随之失效，需要重新签名**。

用法：APK → 打开方式 → 资源表编辑；或直接点开磁盘上的 `.arsc`。逆向面板也有一页「资源」概览。

**点九图**：`npTc` 块保存拉伸区，四边各 1 像素保存拉伸与留白标记。
编辑器把 1 像素的边放大成 20dp 宽的格子，点格子切换黑点，
右下留白与整条拉伸有快捷按钮，保存时重新编码 PNG 并在 IHDR 后写回 `npTc`。

## Smali 编辑

APK → 打开方式 → **Smali 编辑**。这一步用 dexlib2 / baksmali 把 `classesN.dex` 摊成
`包路径/类名.smali`，点开任意类就是完整的代码编辑器（语法高亮、查找替换、撤销、跳行都在）。

反汇编结果缓存在 `cache/smali/<包名-大小-时间>/`，第二次打开直接命中；改动过的文件按 `.ok`
标记的修改时间判断，列表右侧会亮一个小点。

顶栏 **编译** 会把改动过的 dex 目录重新汇编（smali 汇编器）、替换进包里的同名条目（其余条目原样复制），
再自动重签成 `<名字>-smali-signed.apk`，可以直接安装。编译失败会给出 smali 报的文件与行号。

改了 dex 的包签名必然失效，所以产物是另存的新文件，不动原件。

## 清单编辑与重签名

APK 的 `AndroidManifest.xml` 是二进制 AXML，普通的文本编辑器打不开。打开方式里选
**清单编辑**：解成文本 → 改 → 保存时编译回 AXML 写进包里（属性名会查 `android.R.attr`
表写 resource map，自定义属性保留名字但没有 id，系统按名找不到就忽略）。

改过清单或 `resources.arsc` 的包签名一定失效，装不上。页面上的 **重签名** 会用运行时
生成的密钥重新签（v1 + v2 + v3），在同目录产出 `xxx-signed.apk`，可以直接安装。
密钥第一次用时生成并存在 `files/transpile`，之后复用，所以同一个包多次重签签名一致。

对 MT 插件来说这一步不需要：`.mtp` 是 zip 源码包，本身没有签名，装进去就能跑。

## MCP 服务

设置 → 开发者 → MCP 服务。打开后会绑定 `127.0.0.1`（外部设备无法直连），
用 JSON-RPC 2.0 over HTTP 暴露一组文件工具，端点 `http://127.0.0.1:8686/mcp`，
请求头带 `Authorization: Bearer <令牌>`。页面里能复制现成的客户端配置、换令牌、看请求记录。

| 工具 | 作用 |
| --- | --- |
| `device_info` | 型号、系统版本、存储、Root 状态 |
| `list_dir` | 列目录；普通 API 读不到时自动退回 shell |
| `read_file` / `write_file` | 读写文本，二进制用 base64 |
| `file_info` | 大小、时间、权限、可读性 |
| `search` | 按名称递归搜索，可选内容包含 |
| `archive_list` | 列 zip / 7z / rar / tar 内容 |
| `shell` | 执行命令，可选 `as_root` |
| `copy_path` | 复制或移动 |
| `read_package` | 读 APK 包名、版本、SDK、权限数 |

电脑上连接：`adb forward tcp:8686 tcp:8686`，再把上面的地址粘进客户端即可。

## 设计规范

- **色板**：中性灰阶，两套主题只换明度不换色相。黑夜 `#0D0D0D → #171717 → #1F1F1F → #262626 → #2E2E2E`，白天 `#F2F2F2 → #FFFFFF → #ECECEC → #E3E3E3`；分隔线 `#343434 / #DCDCDC`，强调色蓝 `#4C8DFF / #1F6FEB`。层级只用 1%–3% 的明度差，不用描边黑框。
- **度量**：顶栏与全屏页头 56dp，底栏 50dp，列表行 50dp、图标 30dp、左内边距 12dp；字号 17（页标题）/ 14（文件名）/ 10（时间与大小）。这些数字集中在 `Mt` 令牌里，页面不再各写一套。
- **列表**：文件名为 14sp 常规字重，副标题「时间 大小」用 10sp 三级文字色，时间格式 `yy-MM-dd HH:mm`，大小紧凑写（`18.74M`），半栏 180dp 下也能整行放下。
- **少即是多**：不在界面上写解释性副标题，用图标、位置与留白表达含义。
- **字重**：暗色下整体降一档，抵消亮字光渗。
- **数字**：容量与文件大小保留两位小数（属性、存储统计），列表用紧凑写法。
- **动效**：统一 180 / 300 / 380 / 460 / 600 ms 与 ease-in / ease-out / ease-in-out 令牌，整体放慢一档再看得到「从哪来、到哪去」。层级切换左右推开、路径变化淡入上移、补全浮层弹性出现、底栏多选变形、栏聚焦底色过渡、按压回弹、数字滚动、骨架屏、汉堡变叉、圆形扩散、对勾粒子。
- **图标**：文件夹为实心双层造型；文件为 MT 式「彩色圆角方块 + 白纸 + 扩展名」，颜色随类型（`.py` 蓝、`.zip` 棕、`.apk` 绿）；图片与视频直接显示首帧缩略图。
- **聚焦**：两栏之间只有一条内容色细线；当前栏靠底色与内容亮度区分，不再出现蓝色高亮线。

## 权限

- `MANAGE_EXTERNAL_STORAGE`：Android 11+ 全盘读写（需在系统设置中授予）

## 已知限制

- **`/`、`/system`、`/vendor`、`/product`、`/apex`、`/sdcard` 不需要 Root 或 Shizuku**：应用用自己的 uid 就能读，文件管理器与终端走同一条本地 shell 通道。**`/data` 及其子目录**（包括其他应用的私有目录）受内核 DAC 与 SELinux 限制，任何非 root 应用都读不到 —— Termux 非 root 模式同样如此，这不是本应用缺功能。需要时在设置里接入 Shizuku（shell 身份）或 Root。
- `Android/data`、`Android/obb` 在 Android 13 起连 SAF 也逐步收紧，个别 ROM 会拒绝授权，这时只能靠 Root。
- 远程协议以「能用」为准：SMB 不写共享名时只探测常见共享（smbj 不提供 NetShareEnum）；S3 上传使用 UNSIGNED-PAYLOAD，部分强制签名的私有部署需要改用支持预签名哈希的服务端配置。
- 压缩包：zip / 7z / rar / tar / tar.gz / tar.bz2 / tar.xz / gz / bz2 / xz 均可浏览与解压；创建支持 zip / 7z / tar / tar.gz，其中 **AES-256 密码仅 ZIP**（7z 写入侧加密库不完整，暂不提供）。RAR5 的个别压缩算法可能解不出，会明确提示。
- 老式 doc / xls / ppt 走二进制抽样（Word 的 piece table、Excel 的 BIFF8、PPT 的 TextCharsAtom），只保证文字与表格能读出来，样式与图片不还原。
- 超过 12 万字的文本自动关闭整篇着色与补全（整段重排已经很重，优先保证输入流畅）；打开超过 32 MB 的文件会提示改用十六进制编辑器。
- 分段载入的超长文件暂不支持撤销 / 重做，避免与未载入的尾部错位。
- 十六进制编辑器单次最多载入 6 MB；更大的文件只读浏览，保存按钮会隐藏，避免只写回前半段。
- **逆向做到「看 + 改」全流程**：AndroidManifest 反编译与回编译、dex 浏览、签名与组件信息、
  资源表读写、**Smali 反汇编与回汇编**、v1+v2+v3 重签名。改过的包签名必然失效，安装前需要重签
  （页面里的「重签名」或 Smali 编辑的「编译」都会自动做）。
- **MT 插件与 jar 走解释执行**：插件源码由内置解释器跑，`libs/*.jar` 由字节码解释器跑，
  JDK 与 Android 常用类通过反射调用。反射回调（宿主把接口回调进插件对象，例如 `Collections.sort`
  的 Comparator）不支持；lambda（`invokedynamic`）不支持。遇到没覆盖的语法、指令或类时会明确报错，
  不会静默失败。
- 最低支持 Android 8.0（API 26）：7z / xz 解码依赖 `java.nio.file`，低版本无法保证稳定。
- 编辑器暂不支持多文件标签页（MT 的「保留文件」），关闭时会提示保存；终端直接调用系统 `sh`，没有内置 bash / coreutils 扩展包，`ls -l` 等行为以系统自带实现为准。
